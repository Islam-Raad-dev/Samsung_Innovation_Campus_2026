### What the program covers

1. Introduction to Artificial Intelligence
2. Math for Data Science: linear algebra (vectors, matrices) and derivatives
3. Exploratory Data Analysis: NumPy and Pandas, data preprocessing and visualization
4. Probability and Statistics: distributions, descriptive and inferential statistics, hypothesis testing
5. Machine Learning 1, Supervised Learning: regression, classification, Decision Trees, Naive Bayes, KNN, SVM, Ensemble methods
6. Machine Learning 2, Unsupervised Learning: hierarchical and non-hierarchical clustering, dimensionality reduction
7. Natural Language Processing: text mining, text preprocessing, language models, NLP with Keras
8. Neural Networks and Deep Learning: fundamentals, TensorFlow and Keras
9. Various Deep Learning Topics: CNN, RNN, GAN
10. Practical Use and Fine-Tuning of Large Language Models: Hugging Face, fine-tuning, model optimization, applications

The program ends with a **team Generative AI Capstone Project** that tackles a real-world problem.

## Getting started

```bash

git clone https://github.com/<your-username>/<repo-name>.git
cd <repo-name>

# 2. Create and activate a virtual environment
python -m venv .venv
source .venv/bin/activate        # Windows: .venv\Scripts\activate

# 3. Install dependencies
```
